# AIEasyMusic
输入一句话，生成乐谱和音乐，ai让音乐生成变的简单。歌词生成，乐谱生成，音乐生成，配乐生成，歌曲生成，背景音乐生成

## 项目介绍

**Easy Music · AI 写歌与简谱创作平台**

[在线体验](http://easymusic.petaiworkshop.cn/) · [产品总览](http://www.petaiworkshop.cn)   [windows客户端免安装](https://easymusic.petaiworkshop.cn/download/v0.1/EasyMusic-Setup-0.1.0-win-x64.exe). [windows客户端安装版本](https://easymusic.petaiworkshop.cn/download/v0.1/EasyMusic-Portable-0.1.0-win-x64.exe)

把一句话想法，变成可编辑的简谱、可试听的旋律，以及可导出的 AI 演唱 / 伴奏 / 完整歌曲。面向内容创作者、音乐爱好者、教学与短视频场景——**不必先懂乐理**。

### 核心能力

| 能力 | 说明 |
|------|------|
| **AI 写词写曲** | 输入诉求，生成歌词与旋律结构 |
| **简谱编辑** | 内嵌简谱编辑器：预览、改谱、试听 |
| **AI 演唱** | 多声库歌声合成（ DiffSinger） |
| **纯伴奏** | 根据选择的乐器音色生成伴奏轨 |
| **完整歌曲** | 人声 + 伴奏混音导出 |
| **多格式导出** | 123 / ABC / MIDI / MusicXML 等 |

### 创作模式

- **乐谱生成**：一句话生成词曲与简谱，右侧可继续编辑  
- **纯伴奏**：只要伴奏轨，适合 BGM、演示  
- **纯人声**：只要演唱轨，适合试听人声效果  
- **完整歌曲**：人声与伴奏合成一条成片  

### 适合谁用

- **短视频 / 自媒体**：快速出可唱可剪的歌  
- **音乐爱好者**：从想法到简谱再到成曲  
- **教学与启蒙**：看得见的简谱 + 可听的试听  
- **游戏 / 独立创作者**：原型配乐与人声草稿  
- **播客 / 口播**：片头片尾或主题小调  

### 产品特点

- **三步出歌**：生成 → 编辑简谱 → 合成音频  
- **看得懂的谱**：简谱预览，不是黑盒音频  
- **可改可导出**：源码与多种乐谱格式互通  
- **积分与会员**：按功能消耗积分；会员套餐可微信扫码充值（桌面版）  
- **网页 + 桌面**：浏览器访问；Windows 安装包打开同一线上服务  

### 怎么开始

1. 打开 [Easy Music](http://easymusic.petaiworkshop.cn/)（或安装桌面版）  
2. 注册 / 登录，确认积分或会员  
3. 在工作台填写音乐诉求，生成乐谱  
4. 在右侧简谱区试听、修改  
5. 选择声库与音频类型，合成并下载
